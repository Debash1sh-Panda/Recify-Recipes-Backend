# 🍽️ Recify – Recipes, Simplified

Recify – Recipes, Simplified is a modern **MENN Stack** (MongoDB, Express, Next, Node.js) based web application for food lovers.  
Users can **explore, upload, and share** recipes while also saving favorites, planning meals, and discovering trending cuisines.  

---

## 🚀 Features
- 🔎 **Search & Filter Recipes** by ingredients, cuisine, or cooking time  
- 📝 **Upload Your Recipes** with photos & step-by-step instructions  
- ⭐ **Save & Favorite Recipes** for easy access later  
- 📅 **Meal Planner** to organize weekly meals  
- 👩‍🍳 **Cooking Mode** – step-by-step interactive recipe guide  
- 📷 **Image & Video Support** for better cooking experience  
- 👤 **User Profiles** to manage uploaded and saved recipes
